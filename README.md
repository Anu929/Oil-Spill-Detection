# 🌊 Oil Spill Detection & Prediction Dashboard

AI-powered dashboard to predict marine oil spill incidents globally using machine learning. Forecasts large and medium oil spills from 2025-2034 based on 50+ years of historical data.

---

## ✨ Features

- 🔮 **AI Predictions** - Get forecasts for large and medium oil spills
- 📊 **Interactive Charts** - Zoom, pan, and hover for detailed insights
- 📈 **Historical Analysis** - Visualize 50+ years of spill data (1970-2023)
- 🎯 **Year Comparison** - Compare different years side-by-side
- 💡 **Clean Interface** - Modern, easy-to-understand design

---



## 🚀 Quick Start

### Installation
```bash
git clone https://github.com/Anu929/Oil-Spill-Detection.git
cd Oil-Spill-Detection
pip install -r requirements.txt
```

### Run the App
```bash
streamlit run app.py
```

Open your browser at: **http://localhost:8501**

---

## 📊 How It Works

1. **Load Data** - Historical oil spill data from 1970-2023
2. **Train Models** - Machine learning models for large and medium spills
3. **Make Predictions** - Select any year (2025-2034) to get forecasts
4. **Visualize** - Interactive charts show trends and predictions
